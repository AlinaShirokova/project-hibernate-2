## Предложения по улучшению структуры

По заданию структуру таблиц менять нельзя, но нужно внести свои предложения по улучшению.
1) Нужно добавить **foreign key** в таблице `film_text` на поле `film_id` таблицы `film`.

2) Можно сделать **класс предок для всех сущностей**
- В него можно вынести `id`.
  Для этого у всех сущностей название поля должно быть `id`, без уточнения имени сущности как в `film_id`.
  Также тип данных у `id` для всех сущностей нужно сделать одинаковым.

- Поле `last_update` тоже можно вынести в эту сущность, если его добавить везде, где сейчас отсутствует.

3) **Удалить** колонку `original_language_id` в `film`.
   Сейчас в ней все значения `null`, значит её можно удалить без потери данных.

4) Колонку `special_features` лучше **изменить**.
   Сейчас там хранится строка, склеенная из нескольких значений `enum Feature`. Для этой колонки лучше сделать тип связи `ManyToMany`. Это позволит упростить запросы для поиска всех записей, когда одна категория Feature есть, а другой нет.

5) В колонке `rating` было бы проще использовать **рейтинги без дефисов и пробелов**.
   `PG13` вместо `PG-13` и `NC17` вместо `NC-17`. Тогда можно обойтись без конвертера.
